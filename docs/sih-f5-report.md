# SIH-F5 final engineering report

SIH-F5 continues the interrupted worktree. It does not restart F5, retrain the deployed model or perform final scientific revalidation. The initial audit and first failing fixture are recorded in [resumption audit](sih-f5-validation/resumption-audit.md). Detailed limits are in [architecture](sih-f5-architecture.md); measured results are in [performance](sih-f5-performance-report.md).

1. **TLS parser architecture.** Independent passive wire/record/hello readers feed a bounded state owner alongside the existing canonical pipeline. No second model or scientific feature path was introduced.
2. **Bounded reassembly design.** Per-direction data/presence arrays support contiguous, split-record, split-handshake, reordered-prefix, sequence-wrap and identical-overlap cases within a capped range. Conflicting overlap is rejected; terminal results release buffers. Capture-watermark deadlines, LRU and tuple-epoch checks bound retention. This is first-hello metadata reassembly, not a full TCP stack.
3. **Supported TLS metadata.** ClientHello/ServerHello record and legacy versions, offered/selected versions, ciphers, compression, extension IDs, groups, point formats, signature algorithms, observable SNI/ALPN, session-ID length and HRR flag. Hidden or unobserved fields stay unavailable.
4. **Parser safety limits.** Defaults: 256 connections, 32768-byte span per direction, 10-second handshake deadline, 60-second connection TTL, 64 packet samples per connection. Fixed caps include 16384-byte record/hello, 8 records, 256 ciphers, 64 extensions, 4096-byte extension, 128 groups/signature algorithms, 16 ALPN items and one 253-byte SNI. Full bounds and configuration maxima are documented in architecture. Strict nested lengths, duplicate detection and status distinctions are tested.
5. **JA3 implementation/result.** Standard ordered decimal five-field canonical string, GREASE removal, then standard MD5 identifier. Canonical string is retained. Published deterministic vectors, empty extensions and GREASE fixtures pass. No reputation lookup or malware interpretation.
6. **JA3S implementation/result.** Ordered version/selected-cipher/extension canonical string and MD5. Literal vector `771,4865,43-51` yields `f4febc55ea12b31ae17cfb7e614afda8`. The legacy version field is used for the fingerprint, with negotiated version displayed separately.
7. **JA4 implementation status.** **NOT IMPLEMENTED.** No exact verified local specification and deterministic vectors were established. The API/UI explicitly disclose this; no approximation is presented as JA4.
8. **QUIC parser architecture.** Independent bounded visible-header reader. v1 type layouts are interpreted only after invariant checks; unknown versions expose invariants without guessing v1 type semantics.
9. **Supported QUIC metadata.** Long-header flag, version, v1 Initial/0-RTT/Handshake/Retry type, CID lengths/SHA-256, visible token/declared length and version-negotiation list. First packet only; protected fields and short-header CID inference are unavailable. Later unsupported short headers do not erase a retained long-header observation.
10. **Explicit decryption boundary.** No TLS application-data or QUIC Initial/payload decryption, key extraction, MITM, certificate interception, active handshake, probe, packet injection, resolver, reputation lookup or external telemetry. CCS terminates pre-hello inspection conservatively. Tests prohibit active networking/decryption in F5. Validation used synthetic local PCAPs and loopback API/WS only.
11. **Unidirectional semantics.** Client-only, server-only and both are supported; QUIC discloses one versus both observed directions. Missing peer traffic is unobserved, never an inferred failure, block or compromise.
12. **Behavioral evidence.** Observable hello/version/cipher/extension/SNI/ALPN/fingerprint and QUIC header/version/CID/VN context plus bounded packet-size/IAT summaries. No heuristic attack thresholds, malware verdicts, secret classifier or cross-session attribution. Transport samples include ACKs/retransmissions and disclose sample scope/capping.
13. **Event integration.** Additive TLS/QUIC status/observation/evidence persist through SQLite and authenticated REST/WS. Two end-to-end delivery cases verify equality. Existing scientific scores, severity/risk, provenance and F3/F4 evidence remain intact. Operational F5 failures are isolated and counted.
14. **SOC integration.** One restrained ENCRYPTED SESSION section on Detection Detail and operational Sensor counters. MEASURED/DERIVED/UNAVAILABLE, fingerprint canonical detail, ECH/one-way limits and no-decryption text are visible. Actual fixture events passed 1440/390-pixel browser checks without overflow or page errors. No SOC redesign or product-page change.
15. **Privacy/retention decisions.** Visible SNI persists normalized to lowercase ASCII under existing authenticated local event retention, bounded to 253 bytes. ECH outer-only and absent SNI are explicit. CIDs are hashed but remain linkable. No new raw TLS records, random/session values, key shares, tokens or application bytes are persisted/logged. Transient reassembly is bounded and released on completion/expiry.
16. **Bounded-state design.** Two directions maximum; connection count/byte span/sample/TTL limits and deterministic eviction. Default reassembly arrays have a 32 MiB ceiling plus bounded objects/copies; benchmark uses 64 connections and an 8 MiB ceiling. Quiet capture does not advance capture-time expiry. Existing exact canonical flow histories remain an accepted separate growth limit.

All enabled runs had zero F5 processing errors and state peaks at or below 64. One run per mode does not establish statistical significance or production capacity.
25. **False-positive/coverage limitations.** Metadata creates no new attack verdict, but no population false-positive rate is estimated. Shared/spoofable fingerprints, legacy TLS, missing SNI, unknown QUIC versions and normal ALPN are not malicious by themselves. First hello only; no arbitrary midstream synchronization, post-completion overlap adjudication, second HRR hello, STARTTLS, IP-fragment/IPv6-extension reconstruction, QUIC decryption/v2 type parsing/migration/coalesced-packet walk or certificate analysis. ECH inner names and encrypted ALPN are unavailable. Eviction, capture gaps, long flow duration and strict segmentation guards can omit metadata.
