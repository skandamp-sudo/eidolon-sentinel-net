# RF-1 — offline legacy fixture correction

RF-1 is resolved for the inspected Scapy serialization path. Release Freeze may resume as a separate phase; this correction does **not** complete the freeze or authorize publication/presentation work. Existing freeze reports and hygiene edits were preserved byte-for-byte.

1. **Root cause.** `Ether()` left destination MAC unspecified. Installed Scapy `DestMACField.i2m` calls `conf.neighbor.resolve`, whose IPv4 path reaches `scapy.layers.l2.getmacbyip`; an uncached address can trigger `srp1`/ARP. Missing Ethernet source MAC invokes `SourceMACField.i2h`, `pkt.route()` and `resolve_iface(...).mac`. ARP's default source IP likewise consults routing state through `SourceIPField`. These paths were inspected before editing; no live-network reproduction or permission elevation was used in this correction.
2. **Source locations.** `tests/fixtures/generate_test_pcap.py`: synthetic mapping at lines 9–13; Ethernet constructions at lines 22, 28, 35, 43, 48; ARP frame at lines 55–58. Every Ethernet frame now has explicit source and destination addresses. Existing IP data-packet addresses, ports, payloads, counts, relative timing and protocol flags are unchanged.
3. **Synthetic mapping.** Client `192.168.1.100` → `02:00:00:00:00:01`; TCP peer `10.0.0.1` → `02:00:00:00:00:02`; legacy UDP/ICMP peer `8.8.8.8` → `02:00:00:00:00:03`. These fixed synthetic MACs are locally administered and unicast. Reverse TCP uses the reverse MAC pair. The legacy IP values are preserved, not contacted.
4. **ARP decisions.** Ethernet source is the client MAC, destination broadcast `ff:ff:ff:ff:ff:ff`. ARP request `op=1`, `hwsrc` client MAC, `hwdst=00:00:00:00:00:00` (unknown target), `pdst=192.168.1.1` retained. `psrc=192.168.1.100` is now explicit: leaving this formerly host-derived field absent would still violate the no-routing requirement. It matches the logical fixture sender. The parser still skips this one non-IP frame; expected flow semantics are unchanged.
5. **Regression guards.** New `tests/unit/test_offline_fixture_generation.py` guards actual implementation globals and public aliases where present in installed Scapy: `getmacbyip`, `srp1`, `srp`, `sr1`, `sr`, `send`, `sendp`, `get_if_hwaddr`, `resolve_iface`, `sniff`, `AsyncSniffer`; `conf.neighbor.resolve`; IPv4/IPv6 route lookup; L2/L3 socket/listen factories; Python socket construction, connection and DNS lookup functions. Guards raise `pytest.fail` (a BaseException outcome that bypasses ordinary Scapy Exception fallback), with a post-generation zero-call assertion. Warnings are not suppressed. A negative control using the old missing-MAC pattern must trigger the guard before any resolver/network operation executes.
