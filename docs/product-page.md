# Sentinel-NET product page

The public product page is at `/product`. The SOC console remains at `/`, with its existing routes, connection workflow, and visual design. Product code is loaded through a separate route and scoped stylesheet; visiting it does not start a console connection.

## Implementation

- `frontend/src/App.tsx`: public route, lazy loading, console WebSocket cleanup on unmount.
- `frontend/src/pages/ProductSite.tsx`: product page, accessible screenshot tabs/dialog, mobile menu, workflow, project status, draft privacy and terms pages, unknown-page state.
- `frontend/src/styles/product.css`: warm neutral palette, green accent, Avenir/system sans and Georgia typography, responsive layouts, focus and reduced-motion styles.
- `frontend/public/product/`: actual application screenshots, screenshot provenance, and repository MIT license copy.

No dependencies were added or removed. No model, feature extraction, or sensor behavior was changed by this product-page work.

Screenshots were captured from the actual console against an isolated backend containing three records generated by `tests/integration/test_rw1_delivery.py`: synthetic PCAP input, real inference and persistence. They are explicitly labeled synthetic and are not evidence of detection accuracy or production performance.

## Remaining boundaries

The page is implemented locally, not published to a public host. A deployment must serve the SPA fallback for `/product` and its legal routes. The existing SOC's mobile navigation and layout were preserved, not redesigned; the desktop investigation workflow received the full navigation check.

Privacy and terms remain visibly marked drafts. Before offering a hosted service, supply the operator identity and contact, hosting/logging arrangements, retention/deletion practices, data recipients, service commitments, and governing jurisdiction for review. Continuous sensor service packaging and sustained performance validation remain separate planned engineering work, described honestly on the product page.
